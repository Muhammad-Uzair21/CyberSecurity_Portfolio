A hands-on cybersecurity internship covering network reconnaissance, traffic analysis, vulnerability assessment, and web application security.

* Captured and analyzed network traffic using **Wireshark**
* Investigated ICMP and HTTP traffic
* Mapped security findings to **CVE, CVSS, and MITRE ATT&CK**
